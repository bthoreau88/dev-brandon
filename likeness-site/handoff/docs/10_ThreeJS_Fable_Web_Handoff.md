# Three.js / Fable-Style Web Handoff

## Goal
Build the LIKENESS interactive web companion as a browser-based 3D experience that shares the same OVS visual DNA, story data, character locks, and object language as the Unreal game.

## Stack
- React + Vite + TypeScript.
- Three.js for 3D scenes.
- Optional Spark.js for Gaussian Splat rooms.
- GSAP, Theatre.js, or native timeline logic for scroll/camera motion.
- Shared JSON from /data exports.

## Required Routes
- `/` landing page.
- `/motel` interactive motel map.
- `/room-14` 3D room.
- `/tapes` tape archive.
- `/characters` identity cards.
- `/evidence` object timeline.
- `/devlog` production notes.

## Required Visual Features
- Cream/charcoal/olive OVS editorial UI.
- Room 14 as hero interactive scene.
- Brass key 14, locket, tape, mirror, black device.
- Filmic depth and grain pass.
- No unrelated sci-fi UI.

## Fable / Agent Prompt
Build a high-end interactive 3D website for LIKENESS : THE GAME. Use a dark cinematic motel-noir OVS visual system: cream editorial UI, near-black background, muted olive metadata, tungsten practicals, teal shadow, distressed brass accents, subtle film grain. The site must feel connected to an Unreal Engine psychological horror game, not like a separate portfolio page. Create routes for landing, motel map, Room 14, tapes, characters, evidence, and devlog. Use Three.js for an explorable Room 14 scene with inspectable objects: motel key 14, locket, tape, bathroom mirror, desk bell, black device. Store all content in editable JSON. Build with clean components, reusable data schemas, and obvious asset drop zones. Do not hardcode story strings in scene logic. Make the experience expandable.
