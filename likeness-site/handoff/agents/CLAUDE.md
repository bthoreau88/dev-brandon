# CLAUDE.md

## Claude Code Instructions
Read AGENTS.md first. Do not begin coding until you understand the vertical slice scope.

## Unreal Work
Prefer small, testable steps. After every stable change, run or request a play-in-editor test and produce a screenshot or written verification.

## Blueprint Discipline
Blueprints must be understandable. If a graph becomes complex, summarize what it does and propose refactor boundaries.

## Asset Discipline
Never import assets directly into final directories. Use Content/OVS_LIKENESS/Art_Staging first.

## Session Closeout
End each session with:
- Files changed.
- Systems touched.
- Tests run.
- Screenshots captured.
- Commit hash if committed.
- Next safe task.
