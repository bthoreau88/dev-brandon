# Blender MCP + fal.ai Staging

This folder is for optional asset fabrication experiments and pipeline tests.

Subfolders:
- `/prompts` - reusable prompts for baking, PBR materials, animation, Geometry Nodes scatter, and draft character assembly.
- `/tests` - connection checks and small proof scenes.
- `/staging` - generated or repaired assets before OVS approval.
- `/exports` - clean exports after QA.

Do not place final game assets here. Promote final assets into the main `/assets` flow only after checklist approval.
