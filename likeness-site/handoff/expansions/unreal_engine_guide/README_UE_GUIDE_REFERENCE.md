# Unreal Engine Guide Reference

Use as a study/checklist index. Convert learning topics into LIKENESS tasks. Verify implementation against official docs.

## External reference

- **MrRobinOfficial/Guide-UnrealEngine** — https://github.com/MrRobinOfficial/Guide-UnrealEngine
  Community markdown guide (C++ patterns, gameplay framework, best practices). A *reference
  to read*, not code to install. Most useful for the C++ component work: `UPROPERTY`/
  `UFUNCTION` specifiers, interfaces (`BPI_Interactable`), delegates, timers,
  `UActorComponent` patterns, DataTable access, subsystems — i.e. the room-state, mirror-lag,
  tape, and save/load systems. **Verify any API against UE 5.8** (version not pinned; watch
  for deprecations like `EditorLevelLibrary`). Zero LIKENESS context — general Unreal only.
